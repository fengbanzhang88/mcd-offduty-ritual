## 为什么不是"又一个点餐推荐器"

麦当劳 MCP 把门店、菜单、营养、优惠券、活动开放成一批原子接口，但单个接口都很碎。
本 Skill 的编排逻辑是：**情绪负责传播，接口负责闭环**——

1. **情绪层**：接住"下班那一下"的疲惫感，是社交货币，用户自发转发；
2. **数据层**：推荐来自 `query-meals` 真实在售 + `list-nutrition-foods` 真实营养，不瞎编；
3. **价格层**：`calculate-price` 算**含优惠的真实总价**，先看清楚再决定；
4. **转化层**：认证完成即引导 `available-coupons` → `auto-bind-coupons`，流量变真实订单；
5. **回访层**：按心情/时段组合，同一用户每次结果不同，可反复玩。

## 七步工作流

1. **接住情绪** —— 先共情，问清心情 / 时段 / 调性 / 到店或外送
2. **定时间与餐段** —— `now-time-info` 取真实时间，映射到早餐/午餐/下午茶/夜市/宵夜
3. **识场景 · 请先贤** —— 纯本地零联网，匹配 12 个下班场景，派一位「时空饭搭子」（贴心话 + 典籍题词 + 插画）
4. **找门店** —— `query-nearby-stores` 拿 `storeCode`，**深夜优先 24h 门店**
5. **取真实菜单并筛选** —— `query-meals` + `list-nutrition-foods`，按调性筛
6. **算真实总价** —— `calculate-price`（注意返回单位是「分」）
7. **出卡片 + 彩蛋** —— 渲染 750×1080 卡片；领券/抽奖**确认制**

## 快速开始

### 1. 申请麦当劳 MCP Token

打开 https://open.mcd.cn/mcp → 手机号登录 → 右上角「控制台」→「激活」→ 复制 Token。

### 2. 配置 MCP 连接器（WorkBuddy）

右侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【添加 MCP】，
按下表填入（或直接粘贴 `mcp-config.example.json` 的内容并替换 Token）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

> ⚠️ 把 `YOUR_MCP_TOKEN` 换成你自己的 Token。**配置文件请勿提交真实凭证。**

### 3. 安装 Skill

把本目录整个文件夹放进 WorkBuddy 技能目录（`~/.workbuddy/skills/`），
或在对话里直接说：「我好累，下班了，来点仪式感」。

### 4. 依赖

- Python 3.x
- Pillow（渲染卡片；**没装也能跑**，会自动降级为文本卡片）
- 中文字体：Windows 自带微软雅黑/黑体；其他系统请在
  `scripts/generate_ritual_card.py` 的 `FONT_DIRS` 里改成系统中文字体路径

## 安全与边界

- 领券、抽奖、下单均为**确认制**：先展示内容，用户明确同意才执行
- **不主动调用下单类工具**，支付始终由用户完成
- 仓库与配置中**不含任何真实 Token / 密钥**
- 营养数据仅供参考，**不构成医疗、营养或减重建议**
- 文案不含真人姓名、政治、低俗、地域歧视内容
- MCP 不可用时明确标注「本地快照，非实时」

### 「时空饭搭子」专项红线

- **只养心，不治病**：原话命中敏感词（抑郁/想死/活不下去等）→ 不上先贤，改推全国心理援助热线 **12356**
- **先贤 ≠ 求签**：严禁写成求签/解签/算卦，与麦当劳官方抽奖活动**完全隔离**
- **形象原创**：9 位先贤均为原创 Q 版虚构设计，**不画正脸**（侧影/背影），不临摹任何现存画像；仅作参赛演示与文化交流，**不作商业用途**
- **隐私本地优先**：场景与情绪匹配全程本地完成，用户原话不上传任何云端
