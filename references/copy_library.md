# 仪式感文案库

用法：按「调性 + 时段」取一段模板，**结合用户原话改写**，不要原样照搬。
原则：**先接住，再递上**。先承认他今天不容易，再说这顿饭。

---

## 一、犒劳型（今天很累 / 想对自己好点）

- 今天你已经把该扛的都扛完了。剩下的这点时间，归你自己。
- 不用等谁批准，不用等什么日子。今天下班，就是理由。
- 你今天说过最多的一句话大概是"好的"。现在，换一句："这个我要。"
- 世界今天没对你特别温柔，所以你自己对它好一点。
- 有人用一顿大餐庆祝升职，你也可以用一顿热乎的，庆祝自己又撑过了一天。

## 二、夜归型（22:00 之后 / 加班到现在）

- 这座城市还有灯亮着，其中一盏是你的工位。现在，该换一盏了。
- 24 小时的店不多，但你刚好在，它刚好开着。这就够了。
- 深夜不该只有泡面和外卖软件。给你留了一份热的。
- 别人都睡了，你才刚下班。这份宵夜，是你和今天和解的方式。
- 夜再深，也总有一家店亮着灯等你。

## 三、清淡型（不想吃太重 / 有点愧疚）

- 对自己好，不一定要放纵。舒服，也是一种仪式。
- 今天已经够重了，这顿就轻一点吧。
- 养好自己，才有力气继续跟生活过招。

## 四、提神型（还得接着干 / 明早还要早起）

- 还没结束是吧。那先把这一口喝完，再上场。
- 你不是不困，你只是还有事没做完。先把电量补上。
- 深夜的清醒很贵，别硬扛。先来一杯。

## 五、随便型（不知道吃啥 / 都行）

- 选择困难的解法，不是继续想，是随便挑一个然后好好吃。
- 都行的时候，就交给今天的心情。它比我懂你。

---

## 结尾句式（接在推荐后面，任选一句）

- 今晚就这样吧。明天的事，明天再说。
- 吃完这顿，今天就算正式结束了。
- 希望你今天最后记住的，不是报表，是这一口热的。
- 打卡下班。你今天，辛苦了。

```
[3-8s]  共情：今天你把该扛的都扛完了，剩下的时间，该归你自己。
[8-13s] 递上：这份（XX），（XX）元，约（XX）大卡。真的，不贵。
[13-15s] 收尾：吃完这顿，今天就算正式结束了。
```
